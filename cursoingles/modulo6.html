🔢 2. Countable vs Uncountable

En inglés, las cosas se dividen en contables e incontables.

📊 Contables (Countable)

Puedes contar: 1, 2, 3...

  • Apple → One apple, two apples
  • Orange → Three oranges
  • Cookie → Five cookies

📊 Incontables (Uncountable)

No puedes contar en unidades.

  • Water → Some water, a lot of water
  • Milk → Some milk, a glass of milk
  • Rice → Some rice, a kilo of rice

💡 4. Grammar: SOME, ANY y WOULD LIKE

SOME (Afirmativo)

Para pedir o dar cosas (forma educada)

  • I want some water.
  • Can I have some bread?
  • There is some milk.

ANY (Negativo/Preguntas)

Para preguntas y negativos

  • Do you have any questions?
  • I don't want any coffee.
  • Is there any water?

WOULD LIKE (Más educado que WANT)

  • I want a coffee. (informal)
  • I would like a coffee. (educado)
  • I would like some water, please. (MUY educado)

🍴 5. Phrases para el Restaurante

👤 Como Cliente:

  • "I would like some water, please."
  • "Can I see the menu, please?"
  • "The bill, please." (La cuenta)
  • "Do you have any...?"

👨‍🍳 Como Mesero:

  • "What would you like?"
  • "Here you are." (Aquí tiene)
  • "Sorry, we don't have any..."
  • "Enjoy your meal!"

✏️ 6. Ejercicios Prácticos

📝 Completa con SOME o ANY:

I want _____ water, please.
Do you have _____ questions?
I don't want _____ coffee.

📝 Transforma a forma educada:

"I want water" → "I _____ _____ water, please."
"She wants some bread" → "She _____ _____ _____ bread."
