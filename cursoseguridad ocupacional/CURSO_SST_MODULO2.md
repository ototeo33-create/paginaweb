### 2.2 METODOLOGÍA DE MATRIZ DE RIESGOS (GTC 45)

La Guía Técnica Colombiana GTC 45 proporciona una metodología para evaluar riesgos laborales.

#### PASO 1: IDENTIFICAR EL PELIGRO
- Observar el entorno de trabajo
- Revisar accidentes e incidentes anteriores
- Consultar con trabajadores
- Analizar tareas específicas

#### PASO 2: DETERMINAR CONSECUENCIAS
| Nivel | Consecuencia | Ejemplo |
|-------|-------------|---------|
| 1 | Lesión menor (sin incapacidad) | Rasguño, moretón |
| 2 | Lesión con incapacidad temporal | Fractura, esguince |
| 3 | Lesión con incapacidad permanente | Amputación, pérdida de visión |
| 4 | Muerte | Fatalidad |

#### PASO 3: EVALUAR PROBABILIDAD
| Nivel | Probabilidad | Descripción |
|-------|-------------|--------------|
| 1 | Muy baja | Solo en circunstancias excepcionales |
| 2 | Baja | Rara vez sucede |
| 3 | Media | Ocurre algunas veces |
| 4 | Alta | Ocurre frecuentemente |
| 5 | Muy alta | Es esperado que ocurra |

#### PASO 4: CALCULAR NIVEL DE RIESGO

**NR = Probabilidad × Consecuencia**

| NR | Clasificación | Acción |
|----|---------------|--------|
| 1-4 | Acceptable | Mantener controles existentes |
| 5-9 | Bajo | Mantener y mejorar controles |
| 10-16 | Medio | Implementar controles pronto |
| 17-24 | Alto | Acción inmediata |
| 25 | Crítico | Actividad suspendida hasta control |

#### EJEMPLO PRÁCTICO:

```
PELIGRO: Trabajo en alturas sin arnés
PROBABILIDAD: Alta (4)
CONSECUENCIA: Muerte (4)
NIVEL DE RIESGO: 16 (ALTO)

CONTROLES NECESARIOS:
✓ Arnés y línea de vida
✓ Supervisor de altura
✓ Procedimiento escrito
✓ Capacitación certificada
✓ Redes de seguridad
```

### 2.3 JERARQUÍA DE CONTROLES

```
┌────────────────────────────────────────────────────────────────────┐
│                    JERARQUÍA DE CONTROLES                          │
│                  (Orden de prioridad - Mayor a Menor)              │
└────────────────────────────────────────────────────────────────────┘

1️⃣  ELIMINACIÓN          ┌────────────────────────────────────┐
   (Eliminar el peligro) │ ¿Podemos eliminar completamente    │
                         │ el peligro?                        │
                         └────────────────────────────────────┘
                              ⬆️ MÁS EFECTIVO

2️⃣  SUSTITUCIÓN          ┌────────────────────────────────────┐
   (Cambiar por algo      │ ¿Podemos usar algo menos          │
    menos peligroso)      │ peligroso?                         │
                         └────────────────────────────────────┘

3️⃣  CONTROLES DE         ┌────────────────────────────────────┐
   INGENIERÍA             │ ¿Podemos isolate el peligro       │
   (Aislamiento física)   │ con machinery o barreras?          │
                         └────────────────────────────────────┘

4️⃣  CONTROLES            ┌────────────────────────────────────┐
   ADMINISTRATIVOS        │ ¿Podemos cambiar cómo trabaja      │
   (Cambios enprocedimiento)│ la gente?                         │
                         └────────────────────────────────────┘

5️⃣  EPP                  ┌────────────────────────────────────┐
   (Protección personal)  │ ¿Podemos proteger a la persona     │
                         │ con equipos?                       │
                         └────────────────────────────────────┘
                              ⬇️ MENOS EFECTIVO
```

#### EJEMPLO DE APLICACIÓN:

**Peligro: Pintura con solventes tóxicos**

| Nivel | Control | Ejemplo |
|-------|---------|---------|
| 1 | Eliminación | Eliminar el proceso de pintura |
| 2 | Sustitución | Usar pintura base agua |
| 3 | Ingeniería | Cabina de extracción con ventilador |
| 4 | Administrativo | Rotación de trabajadores, señalización |
| 5 | EPP | Respirador, guantes, gafas |

### 2.4 INSPECCIONES DE SEGURIDAD

#### TIPOS DE INSPECCIÓN

**Planificadas:**
- Calendario establecido
- Checklist predefinido
- Inspectores capacitados
- Documentadas y archivadas

**No Planificadas (De rutina):**
- Observación directa del supervisor
- Corrección inmediata de condiciones inseguras
- Registro en bitácora

#### CHECKLIST DE INSPECCIÓN


### 2.5 ELABORACIÓN DEL MAPA DE RIESGOS

El mapa de riesgos es una representación visual de los riesgos en el lugar de trabajo.

**Elementos del mapa:**
- Distribución física del área
- Ubicación de peligros identificados
- Niveles de riesgo por zona
- Ubicación de equipos de emergencia
- Rutas de evacuación
- Puntos de encuentro

**Colores estándar:**
| Color | Significado |
|-------|------------|
| Rojo | Peligro alto |
| Naranja | Peligro medio |
| Amarillo | Precaución |
| Verde | Zonas seguras |
