### 3.1 TRABAJO EN ALTURAS

**Definición:** Toda labor que se realice a más de 1.8 metros sobre el nivel inferior.

#### REQUISITOS PARA TRABAJO EN ALTURAS:

**1. Capacitación:**
- Mínimo 8 horas teóricas + 4 horas prácticas
- Certificación vigente (válida por 1 año)
- Actualización anual

**2. Evaluación médica:**
- Aptitud para trabajo en alturas
- Vigencia según criterio médico

**3. Sistemas de protección contra caídas:**

```
┌─────────────────────────────────────────────────────────┐
│           SISTEMAS DE PROTECCIÓN EN ALTURAS             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   ANCLAJE ────── LÍNEA DE VIDA ────── ARNÉS             │
│   (Punto fijo)   (Cable horizontal/  (Arnés cuerpo       │
│                  vertical)          completo)           │
│                                                         │
│   + ABSORBEDOR DE IMPACTO                               │
│   + CONECTOR / REATA                                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**4. Componentes del arnés:**
- Banda para muslos y cintura
- Cinta dorsal para ascenso
- Anillo "D" dorsal (para arresto de caídas)
- Indicador de impacto (si aplica)

#### PROCEDIMIENTO SEGURO:

```
PASO 1: Solicitar permiso de trabajo
PASO 2: Verificar aptitud médica y capacitación vigente
PASO 3: Realizar evaluación de riesgos
PASO 4: Identificar punto de anclaje resistente (mínimo 5,000 lbs)
PASO 5: Instalar línea de vida o sistema de posicionamiento
PASO 6: Verificar equipos antes de usar
PASO 7: Usar arnés correctamente ajustado
PASO 8: Mantener tres puntos de contacto
PASO 9: No trabajar solo - supervisor debe estar presente
PASO 10: Desmontar en orden inverso
```

### 3.2 ESPACIOS CONFINADOS

**Definición:** Área con aberturas limitadas de entrada/salida, ventilación deficiente, no diseñada para ocupación continua.

**Ejemplos:**
- Tanques, silos, tolvas
- Pozos, cámaras, conductos
- Tuberías de gran diámetro
- Cuartos de máquinas

#### CLASIFICACIÓN DE ATMÓSFERA:

| Tipo | O₂ | Riesgo |
|------|-----|--------|
| Rica en O₂ | >23.5% | Incendio/explosión |
| Normal | 19.5-23.5% | Aceptable |
| Deficiente | <19.5% | Hipoxia |
| Peligrosa | <16% | Pérdida de consciencia |

#### PROCEDIMIENTO DE INGRESO:

```
┌──────────────────────────────────────────────────────────────┐
│              PERMISO DE TRABAJO EN ESPACIO CONFINADO         │
└──────────────────────────────────────────────────────────────┘

ANTES DE ENTRAR:
□ Evaluar atmósfera (O₂, gases inflamables, tóxicos)
□ Ventilar hasta condiciones seguras
□ Bloquear energías (eléctrica, mecánica, hidráulica)
□ Identificar rescue plan y equipo
□ Designar vigilante externo
□ Comunicar a todos los involucrados

DURANTE EL TRABAJO:
□ Monitorear atmósfera continuamente
□ Mantener comunicación con vigilante
□ Usar equipo de protección según riesgo

DESPUÉS DEL TRABAJO:
□ Retirar herramientas y materiales
□ Verificar que el espacio esté limpio
□ Cerrar/abrir según corresponda
```

### 3.3 BLOQUEO Y ETIQUETADO (LOTO - Lockout/Tagout)

**Definición:** Procedimiento para asegurar que máquinas y equipos estén parados y no puedan ser energizados durante mantenimiento o limpieza.

#### PASOS DEL LOTO:

```
BLOQUEO Y ETIQUETADO - SECUENCIA DE 8 PASOS

1. PREPARACIÓN
   └─> Identificar todas las fuentes de energía
   └─> Revisar planos y diagramas

2. NOTIFICACIÓN
   └─> Informar a trabajadores afectados
   └─> Explicar trabajo a realizar

3. PARADA DE EQUIPO
   └─> Seguir procedimiento normal de parada
   └─> Usar botones de parada designados

4. AISLAMIENTO DE ENERGÍAS
   └─> Desconectar: eléctrica, mecánica, hidráulica, neumática
   └─> Cerrar válvulas, interruptores

5. APLICACIÓN DE DISPOSITIVOS DE BLOQUEO
   └─> Candados individuales (uno por persona)
   └─> Verificar que no se puede energizar

6. DISIPACIÓN DE ENERGÍAS RESIDUALES
   └─> Descomprimir sistemas hidráulicos
   └─> Descargar resortes
   └─> Bloquear partes móviles

7. VERIFICACIÓN
   └─> Intentar encender equipo
   └─> Confirmar que no hay movimiento
   └─> Probar controles (botones, sensores)

8. TRABAJO DE MANTENIMIENTO
   └─> Realizar trabajo requerido
   └─> Retirar herramientas
   └─> Reintegrar a producción
```

#### COLORES DE ETIQUETAS:

| Color | Significado |
|-------|-------------|
| Rojo | Equipo bloqueado - NO OPERAR |
| Amarillo | Mantenimiento en proceso |
| Naranja | Energía peligrosa presente |

### 3.4 RIESGO ELÉCTRICO

#### TIPOS DE CONTACTO:

```
┌─────────────────────────────────────────┐
│       CONTACTO DIRECTO                  │
│  Tocarse directamente un conductor      │
│  energizado (fase, neutro)              │
└─────────────────────────────────────────┘
          vs.
┌─────────────────────────────────────────┐
│       CONTACTO INDIRECTO                │
│  Tocarse una parte metálica que se      │
│  energizó por falla de aislamiento      │
└─────────────────────────────────────────┘
```

#### FACTORES QUE AFECTAN LA GRAVEDAD:

| Factor | Efecto |
|--------|--------|
| Voltaje | >50V es peligroso para humanos |
| Amperaje | >30 mA puede causar fibrilación |
| Tiempo de contacto | Menor tiempo = menor daño |
| Recorrido de corriente | Mano a mano = corazón |
| Condiciones húmedas | Aumenta conductividad |

#### MEDIDAS DE PREVENCIÓN:

- Protección de conductores (tubería, canaletas)
- Interruptores diferenciales (30 mA)
- Conexión a tierra
- Mantenimiento preventivo
- Señalización y delimitación
- EPP dieléctrico

| Tipo | Función |
|------|---------|

| Ajustable | Se posiciona según necesidad |
| Retráctil | Se adapta al proceso automáticamente |

### 3.6 ELEMENTOS DE PROTECCIÓN PERSONAL (EPP)

**Principio:** El EPP es el ÚLTIMO recurso, después de todos los controles.

#### SELECCIÓN DEL EPP:

**Debe cumplir:**
- Normas técnicas aplicables (NTC)
- Tamaño adecuado al trabajador
- En buen estado
- Comodidad para la tarea

#### EPP POR TIPO DE RIESGO:

```
RIESGO           → EPP RECOMENDADO
─────────────────────────────────────────────
Caída de objetos → Casco, calzado con punta
Impacto          → Lentes de seguridad, casco
Polvo/Partículas → Gafas, tapabocas
Ruido            → Tapones, orejeras
Calor/Fuego      → Ropa FR, guantes aluminizados
Químicos         → Guantes, gafas, overol
Eléctrico        → Guantes dieléctricos, botas aislantes
Espacios         → Arnés, línea de vida, autónomo
confinados       → SCBA
```

#### VERIFICACIÓN DE EPP:

```
CHECKLIST DE EPP

□ Casco: sin grietas, date vigente
□ Gafas: sin rayones, ajuste correcto
□ Tapabocas: correcto para el contaminante
□ Guantes: sin perforaciones, tamaño adecuado
□ Chaleco: reflectivo visible, sin daños
□ Calzado: punta reforzada, suela antideslizante
□ Arnés: completo, sin cortes en reata
□ Protector auditivo: NRR adecuado para el ruido

FIRMA DE VERIFICACIÓN: _____________ FECHA: _________
```
