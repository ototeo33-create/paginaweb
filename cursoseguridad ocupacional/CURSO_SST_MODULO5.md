#### PROCEDIMIENTO DE EVACUACIÓN:

```
PASO 1: Se activa alarma de emergencia
PASO 2: Mantener la calma, no correr
PASO 3: Abandonar belongings personales (solo lo esencial)
PASO 4: Dirigirse por la ruta asignada
PASO 5: Usar barandillas en escaleras
PASO 6: No usar ascensores
PASO 7: Cerrar puertas sin llave al salir
PASO 8: Ayudar a personas con movilidad reducida
PASO 9: Encontrar punto de reunión
PASO 10: Reportar ausencia de compañeros
PASO 11: Permanecer en punto de reunión hasta autorización
```

### 5.2 TEORÍA DEL FUEGO

#### TRIÁNGULO DEL FUEGO:

```
              CALOR
                ▲
               / \
              /   \
             /     \
            ────────  COMBURENTE (O₂)
           / COMBUSTIBLE \
          ╱─────────────────╲
         ╱                   ╲
        ╱     FUEGO          ╲
       ╱                       ╲

   Para que exista fuego deben estar presentes:
   ✓ Combustible (material)
   ✓ Comburente (oxígeno)
   ✓ Calor (temperatura de ignición)
   ✓ REACCIÓN EN CADENA
```

#### CLASES DE FUEGO:

| Clase | Combustible | Ejemplo | Extintor |
|-------|-------------|---------|----------|
| **A** | Sólidos comunes | Madera, papel, tela | Agua, espuma |
| **B** | Líquidos | Gasolina, alcohol, pintura | CO₂, espuma |
| **C** | Eléctricos | Equipos energizados | CO₂, polvo seco |
| **D** | Metales | Magnesio, titanio | Polvo especial |
| **K** | Aceites | Frituras, grasas cocina | Agente húmedo |

#### TIPOS DE EXTINTORES:

```
┌──────────────────────────────────────────────────────────────┐
│                    TIPOS DE EXTINTORES                       │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  AGUA A PRESIÓN                                              │
│  ✓ Clase A           ✗ NO Clase B, C, K                     │
│  Presión interna, manguera                                  │
│                                                              │
│  CO₂ (Dióxido de Carbono)                                    │
│  ✓ Clase B, C        ✗ NO Clase A, D, K                    │
│  No deja residuo, seguro para equipos                        │
│                                                              │
│  POLVO QUÍMICO SECO (ABC)                                    │
│  ✓ Clase A, B, C     ✗ Puede dañar equipos                  │
│  Multiproposito, más común                                   │
│                                                              │
│  ESPUMA                                                      │
│  ✓ Clase A, B        ✗ NO Clase C, D, K                    │
│  Crea capa que隔绝 oxígeno                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

#### USO DEL EXTintor (PASO A PASO):

```
MÉTODO PASS - Técnica de ataque al fuego

P - PULL (Jalar)
   └─> Jalar el pasador de seguridad

A - AIM (Apuntar)
   └─> Dirigir la boquilla a la base del fuego

S - SQUEEZE (Apretar)
   └─> Oprimir la palanca de descarga

S - SWEEP (Barrido)
   └─> Mover en forma de abanico en la base
```

### 5.3 PRIMEROS AUXILIOS BÁSICOS

#### CONCEPTOS FUNDAMENTALES:

```
PRINCIPIOS BÁSICOS:
├─ Proteger (a usted y a la víctima)
├─ Alertar (llamar ayuda profesional)
├─ Socorrer (actuar sin agravar)
└─ NO mover al lesionado (excepto si hay peligro)
```

#### CADENA DE SUPERVIVENCIA:

```
1. LLAMAR AYUDA     → 123 (Colombia), 112
2. RCP PRECOZ       → Compresiones torácicas
3. DESFIBRILACIÓN   → DEA si disponible
4. SOPORTE VITAL    → Personal médico
```

#### RCP (REANIMACIÓN CARDIOPULMONAR):

```
┌─────────────────────────────────────────────────────────────┐
│                    RCP EN ADULTOS                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ¿Cómo identificar paro cardíaco?                           │
│  → Persona inconsciente                                     │
│  → No respira o jadea (gasping)                             │
│  → No responde a estímulos                                  │
│                                                             │
│  PASOS:                                                      │
│                                                             │
│  1. Verificar seguridad de la escena                       │
│                                                             │
│  2. Verificar respuesta                                     │
│     → Tocar hombros + preguntar "¿Está bien?"              │
│                                                             │
│  3. Llamar ayuda                                            │
│     → "¡Ayuda! ¡Llame al 123!"                              │
│                                                             │
│  4. Verificar respiración (10 seg)                          │
│     → Observar pecho, escuchar, sentir                      │
│                                                             │
│  5. Iniciar RCP                                             │
│     → 30 compresiones torácicas                            │
│     → Ubicación: centro del pecho, sobre el esternón       │
│     → Profundidad: 5-6 cm                                   │
│     → Ritmo: 100-120 por minuto                            │
│                                                             │
│  6. Si sabe: 2 ventilaciones después de 30 compressiones   │
│                                                             │
│  7. Continuar hasta que llegue ayuda o la persona recobre  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### MANIOBRA DE HEIMLICH (Asfixia por cuerpo extraño):

```
┌─────────────────────────────────────────────────────────────┐
│              OBSTRUCCIÓN DE VÍAS AÉREAS                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  SEÑALES:                                                   │
│  → Persona lleva manos al cuello                           │
│  → No puede hablar, toser ni respirar                      │
│  → Piel se pone azul (cianosis)                            │
│                                                             │
│  PASOS:                                                     │
│                                                             │
│  1. Parar detrás de la persona                              │
│  2. Hacer puño con una mano                                 │
│  3. Ubicar entre ombligo y extremo del esternón             │
│  4. Sujetar con la otra mano                               │
│  5. Dar compresiones rápidas hacia adentro y arriba        │
│  6. Repetir hasta que expulse el objeto                    │
│                                                             │
│  EN CASO DE EMBARAZO U OBESIDAD:                           │
│  → Compresiones torácicas (a nivel del esternón)           │
│                                                             │
│  SI LA PERSONA QUEDA INCONSCIENTE:                         │
│  → Bajar al suelo                   │
│  → Iniciar RCP (las compresiones pueden expulsar objeto)   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### HERIDAS Y HEMORRAGIAS:

```
TIPOS DE HEMORRAGIA:
├─ Capilar: Sangrado lento (abrasión)
├─ Venosa: Sangrado oscuro, continuo
└─ Arterial: Sangrado a chorro, rojo brillante (EMERGENCIA)

PRIMEROS AUXILIOS PARA HEMORRAGIA:
1. Usar guantes (bioseguridad)
2. Presionar directamente con tela/gasa limpia
3. Mantener presión constante (10-15 min)
4. Elevar el miembro si es posible
5. NO retirar la primera capa de gasas
6. Si no cede: presionar punto de presión

PUNTOS DE PRESIÓN:
→ Brazo: Cara interna del codo
→ Pierna: Detrás de la rodilla
→ Temporal: Delante de la oreja
```

#### QUEMADURAS:

| Grado | Características | Acción |
|-------|-----------------|--------|
| 1° | Enrojecimiento, dolor | Enfriar con agua 15-20 min |
| 2° | Ampollas, dolor intenso | No romper ampollas, cubrir |
| 3° | Piel blanca/carbonizada, sin dolor | Cubrir, NO aplicar nada, emergencia |

### 5.4 INVESTIGACIÓN DE ACCIDENTES

#### IMPORTANCIA:

> "Accidentes ocurren por causas que pueden identificarse y eliminarse. El objetivo es encontrar la causa, no el culpable."

#### DIFERENCIAS CLAVE:

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  CAUSA INMEDIATA              CAUSA BÁSICA/RAÍZ             │
│  → Lo que pasó                → Por qué pasó                │
│  → Actos inseguros            → Factores personales         │
│  → Condiciones inseguras     │ • Falta de conocimiento    │
│                              │ • Falta de habilidad        │
│                              │ • Fatiga, estrés            │
│                              │ • Motivación inadecuada     │
│                              │                             │
│                              │ Factores del trabajo        │
│                              │ • Herramientas inadecuadas  │
│                              │ • Mantenimiento deficiente  │
│                              │ • Diseño deficiente         │
│                              │ • Supervisión insuficiente  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### MÉTODOS DE INVESTIGACIÓN:

```
1. ÁRBOL DE CAUSAS
   → Parte del evento final
   → Se ramifica hacia atrás
   → until reaching causas raíz

   Ejemplo:
   Accidente: Caída de trabajador
   ├─> Corrió en la escalera
   │   ├─> Quería llegar a tiempo
   │   │   ├─> Meta irreal de producción
   │   │   │   ├─> Sin evaluación de tiempos
   │   │   │   │   └─> No hay procedimiento
   │   │   └─> Bloqueaba puerta de salida
   │   │       └─> Diseño de salida deficiente
```

```
2. MÉTODO DE LOS 5 POR QUÉS
   → Preguntar "¿Por qué?" sucesivamente
   →until llegar a la causa raíz

   Ejemplo:
   ¿Por qué ocurrió la caída?
   → Porque el piso estaba mojado
   ¿Por qué estaba mojado?
   → Porque hubo derrame de aceite
   ¿Por qué había derrame?
   → Porque la máquina tiene fuga
   ¿Por qué tiene fuga?
   → Porque no se le hizo mantenimiento
   ¿Por qué no se hizo mantenimiento?
   → Porque no hay programa de mantenimiento
                                         ↓
   CAUSA RAÍZ: Falta de programa de mantenimiento preventivo
```

```
3. DIAGRAMA DE ESPINA DE PESCADO (ISIKAWA)
   
           ┌──────────────────────────────────────┐
           │              EFECTO                  │
           │         (EL ACCIDENTE)               │
           └──────────────────────────────────────┘
                         ▲
   ┌──────────┬──────────┼──────────┬──────────┐
   │          │          │          │          │
   ▼          ▼          ▼          ▼          ▼
 PERSONAS   MÁQUINAS   MEDIO     MÉTODOS    MATERIALES
  │           │        AMBIENTE     │          │
  ▼           ▼          │          ▼          ▼
 □ Fatiga   □ Fallas   □ Iluminación □ Sin EPP  □ Caducado
 □ Estrés   □ Guardas  □ Ruido      □ Sin proc. □ Tóxico
 □ Desconocimiento
```
