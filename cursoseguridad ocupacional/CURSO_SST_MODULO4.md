## MÓDULO 4: HIGIENE OCUPACIONAL Y ERGONOMÍA

### OBJETIVOS
- Identificar agentes del ambiente de trabajo que afectan la salud
- Aplicar técnicas de medición y control de factores ambientales
- Reconocer la importancia de la ergonomía en la prevención de lesiones
- Implementar pausas activas y prácticas seguras de manipulación de cargas

### 4.1 FUNDAMENTOS DE HIGIENE OCUPACIONAL

**Definición:** Disciplina dedicada al reconocimiento, evaluación y control de los factores ambientales que surgen en el lugar de trabajo y pueden causar enfermedades.

#### AGENTES CONTAMINANTES:

```
┌─────────────────────────────────────────────────────────────┐
│              CLASIFICACIÓN DE AGENTES                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  FÍSICOS          │ Ruido, vibraciones, temperatura,       │
│                   │ radiaciones, iluminación               │
│                                                             │
│  QUÍMICOS         │ Polvos, humos, vapores, gases,         │
│                   │ líquidos, aerosoles                    │
│                                                             │
│  BIOLÓGICOS       │ Virus, bacterias, hongos, parásitos    │
│                   │ (presente en sector salud,              │
│                   │ alimentario, agrícola)                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 RUIDO OCUPACIONAL

#### CONCEPTOS BÁSICOS:

| Concepto | Definición | Unidad |
|----------|------------|--------|
| Sonido | Vibración que se propaga en el aire | dB |
| Ruido | Sonido no deseado que puede dañar | dB(A) |
| Decibelio | Unidad logarítmica de intensidad | dB |

#### NIVELES DE RUIDO Y EFECTOS:

```
0 dB     → Umbral de audición
40 dB    → Biblioteca (seguro)
60 dB    → Conversación normal
70 dB    → Aspiradora (riesgo moderado)
85 dB    → LIMITE inferior - requiere protección ★
100 dB   → Cortacésped - protección obligatoria
110 dB   → Taladro - daño auditivo en 15 min
120 dB   → Umbral del dolor
```

#### LÍMITES MÁXIMOS PERMISIBLES:

| Tiempo de exposición | Nivel máximo |
|----------------------|--------------|
| 8 horas | 85 dB(A) |
| 4 horas | 88 dB(A) |
| 2 horas | 91 dB(A) |
| 1 hora | 94 dB(A) |

#### MEDIDAS DE CONTROL:

```
CONTROL DE RUIDO - JERARQUÍA

1. FUENTE          → Encerrar machinery ruidoso
2. TRAYECTORIA     → Aislamiento acústico, barreras
3. RECEPTOR        → EPP (orejeras NRR 25+ dB)
4. ADMINISTRATIVO  → Rotación, señalización
```

### 4.3 ILUMINACIÓN

#### CONCEPTOS BÁSICOS:

| Término | Definición |
|---------|------------|
| Lumen (lm) | Cantidad de luz emitida |
| Lux (lx) | Cantidad de luz que llega a una superficie |
| Candela (cd) | Intensidad luminosa |

#### NIVELES DE ILUMINACIÓN RECOMENDADOS:

| Actividad | Lux mínimo |
|-----------|------------|
| Pasillos, almacenes generales | 100 lux |
| Lectura, oficinas | 300-500 lux |
| Trabajos mecánicos medianos | 300 lux |
| Trabajos de precisión | 500-1000 lux |
| Laboratorios, salas de cirugía | 1000+ lux |

#### PROBLEMAS POR MALA ILUMINACIÓN:

```
ILUMINACIÓN DEFICIENTE:
├─> Fatiga visual
├─> Dolores de cabeza
├─> Errores de trabajo
└─> Accidentes por falta de visibilidad

ILUMINACIÓN EXCESIVA:
├─> Deslumbramiento
├─> Fatiga ocular
└─> Estrés visual
```

### 4.4 TEMPERATURA Y ESTRÉS TÉRMICO

#### ÍNDICE DE CALOR (IC):

```
IC = Temperatura + (% Humedad × 0.5)

Ejemplo: 30°C + (70% × 0.5) = 35°C IC

TABLA DE RIESGO POR ÍNDICE DE CALOR:

| IC | Riesgo | Recomendación |
|----|--------|---------------|
| <27 | Seguro | Normal |
| 27-32 | Precaución | Aumentar hidratación |
| 32-41 | Atención | Pausas frecuentes |
| 41-54 | Peligro | Pausas frecuentes + vigilancia |
| >54 | Extremo | Solo trabajo esencial |

MEDIDAS DE CONTROL:
□ Hidratación (agua fresca cada 15-30 min)
□ Pausas en zonas frescas
□ Acclimatización gradual (7-14 días)
□ Ropa ligera y respirable
□ Monitoreo de signos de golpe de calor
```

### 4.6 ERGONOMÍA

**Definición:** Disciplina que estudia la adaptación del trabajo al ser humano.

#### TRASTORNOS MUSCULOESQUELÉTICOS (TME):

```
FACTORES DE RIESGO:
├─ Posturas forzadas (prolongadas, incómodas)
├─ Manipulación manual de cargas
├─ Movimientos repetitivos
├─ Vibraciones
└─ Factores psicosociales (estrés, ritmo de trabajo)

PARTES DEL CUERPO AFECTADAS:
├─ Cuello / Cervicales
├─ Hombros / Manguito rotador
├─ Espalda / Columna lumbar
├─ Codos / Epicondilitis
├─ Muñecas / Túnel carpiano
└─ Rodillas / Meniscos
```

#### TÉCNICA CORRECTA DE LEVANTAMIENTO:

```
┌─────────────────────────────────────────────────────────┐
│              LEVANTAMIENTO SEGURO DE CARGAS             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   INCORRECTO              ✓ CORRECTO                    │
│   ┌───┐                   ┌───┐                         │
│   │   │ ← Espalda        │   │ ← Espalda              │
│   │ █ │   doblada        │ █ │   recta                │
│   │   │                  │   │                        │
│   ├───┤ ← Rodillas      ├───┤ ← Rodillas             │
│   │   │   rectas         │   │   flexionadas          │
│   └───┘                  └───┘                        │
│                                                         │
│   ✗ PIE JUNTO                ✓ PIES SEPARADOS           │
│                                                         │
└─────────────────────────────────────────────────────────┘

PASOS PARA UN LEVANTAMIENTO SEGURO:

1. Planificar: ¿Puedo solo? ¿Hay obstáculos?
2. Posicionar pies separados al ancho de hombros
3. Flexionar rodillas, mantener espalda recta
4. Tomar el objeto con ambas manos
5. Cargar cerca del cuerpo
6. Elevar usando las piernas
7. Girarmoviendo los pies, no la espalda
8. Depositar la carga flexionando rodillas
```

#### PESO MÁXIMO RECOMENDADO:

| Condición | Peso máximo |
|-----------|-------------|
| Hombre (sin ayuda) | 25 kg |
| Mujer (sin ayuda) | 15 kg |
| Con ayuda mecánica | Según capacidad del equipo |
| Carga aceptable ideal | < 5 kg (repetitivo) |

### 4.7 PAUSAS ACTIVAS

**Definición:** Breves descansos durante la jornada laboral que incluyen ejercicios de movilización.

#### EJERCICIOS RECOMENDADOS:

```
CADA 60-90 MINUTOS: Pausa de 5 minutos

PARA CUELLO:
→ Rotación suave de cabeza (derecha-izquierda)
→ Inclinación lateral de orejas a hombros

PARA HOMBROS:
→ Elevar y bajar hombros 10 veces
→ Rotación circular hacia adelante y atrás

PARA MUÑECAS:
→ Estirar brazos al frente, doblar muñecas hacia abajo
→ Hacer círculos con las muñecas

PARA ESPALDA:
→ Pararse, inclinarse hacia adelante dejando colgar brazos
→ Estiramiento lumbar sentado (espalda contra silla)

PARA PIERNAS:
→ Caminar breve
→ Estiramiento de cuádriceps (apoyado en una pierna)
```

### 4.8 RIESGOS PSICOSOCIALES

#### FACTORES DE RIESGO:

```
AMBIENTALES        │ Organización del trabajo
│ Iluminación      │ ├─> Carga de trabajo excesiva
│ Ruido            │ ├─> Horarios irregulares
│ Temperatura      │ ├─> Falta de descanso
│ Ergonomía        │ └─> Monotonía
                                          │
VINCULADOS AL      │ RELACIONES SOCIALES │
TRABAJO            │ ├─> Conflicto con compañeros
├─> Alta demanda   │ ├─> Mal clima organizacional
├─> Poco control   │ └─> Acoso laboral
└─> Esfuerzo       │ 
```

#### CONSECUENCIAS:

```
Riesgo Psicosocial → Efectos

├─> Estrés crónico
│   ├─> Ansiedad, depresión
│   ├─> Insomnio
│   ├─> Problemas cardiovasculares
│   └─> Consumod excesode sustancias
│
└─> Síndrome de Burnout
    ├─> Agotamiento emocional
    ├─> Despersonalización
    └─> Baja realización personal
```
